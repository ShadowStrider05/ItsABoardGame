Install ItsABoardGame Launcher

One download link. Install the launcher first, then click Install / Update Game inside the launcher, then click Play.

Download Launcher Installer (Windows)
  1. Download the installer zip and run Install-ItsABoardGameLauncher.cmd.
  2. Launcher opens and installs on your PC.
  3. In launcher, click Install / Update Game.
  4. Click Play to launch.
