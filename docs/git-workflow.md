# Git Workflow

## Branching

- main: production-ready branch
- develop: integration branch when parallel feature work grows
- feature/*: short-lived implementation branches

## Commit Hygiene

- Keep commits focused
- Avoid mixing refactors and feature changes
- Require PR review into main

## Tags

- launcher-vX.Y.Z for launcher build milestones
- game-vX.Y.Z for game milestones
